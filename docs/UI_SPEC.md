# UI 与交互规范 v0.1

统一 EX 系列工具风格，桌面原生窗口行为优先，布局不依赖固定屏幕大小。

## 页面
- 主窗口：左侧导航（远程控制、我的设备、地址簿、连接记录、文件传输、偏好设置）；主区本机 ID、临时密码（仅该功能真实实现后显示）、权限状态、允许远程控制开关、远程 ID/IP 输入、最近连接及服务状态。
- 连接确认：显示远端名称、设备身份指纹/配对码、申请的权限、有效期、接受/拒绝；禁止默认自动接受。
- 会话窗口：独立窗口/标签页，工具栏全屏、屏幕、键盘、文件、声音、画质、更多、断开；状态栏显示真实连接模式、RTT、FPS、编码器、码率、分辨率。未实现功能不提供虚假的可用按钮。
- 设备地址簿：搜索、分组、颜色标记、备注、可信状态、撤销。连接历史可清除；不显示密码。
- 文件传输：本地与远端双栏，明确源/目标方向、进度、取消、冲突处理、失败原因。
- 偏好设置：常规、外观、语言、网络、安全、远程控制、画质、文件、快捷键、更新；窗口大小稳定，不因切换分类自动变化。

## 视觉与可用性
浅色、深色、纯黑、跟随系统；颜色与字号使用统一设计 token。输入、选择、按钮同高度，常规目标 32–36 CSS px；图标语义一致。搜索置于工具栏，不单独占一整栏。可复制文本与不可选界面标签区分，输入支持 IME。对比度、键盘可达性、焦点与状态提示必需。中文和英文首批，后续日语、韩语、法语、德语、西班牙语等；默认跟随系统、可手动切换，UI 不硬编码字符串。

## 会话画面
适应窗口、原始像素、缩放、全屏；明确黑边区域不发送远端鼠标输入；统一坐标转换考虑 DPI、旋转、多屏与 Retina。键盘焦点丢失时清理按下状态；保留本机退出全屏/断开快捷键。会话提示不可关闭至完全不可见；权限不足时引导系统正规授权流程。
