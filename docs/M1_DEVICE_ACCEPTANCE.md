# M1 真实设备验收清单

2026-11-25 · 必须由两台经所有者授权的真实电脑执行。CI 的 synthetic / inert 模式不能替代以下操作。

## 环境及前置
- 记录 host/controller OS、CPU 架构、显示器分辨率及缩放比、提交 SHA、开发包 Actions run、GStreamer 实际版本。
- 从成功的 Desktop development builds 下载各平台对应 artifact，核对构建来源；当前 dev bundle 不包含 GStreamer runtime，需从官方安装匹配的 1.26.11 runtime。不要关闭系统安全检查或授予不必要的管理员权限。
- 两机置于可信私网；使用实际 host IP 与未占用端口，不端口转发、不暴露公网。测试用户可以随时在被控端停止会话。测试窗口仅使用空白编辑器，避免包含私人信息或重要系统。

## 验收
| ID | 场景 | 通过条件 |
|---|---|---|
| A01 | 两平台启动应用和媒体组件 | 实际打开桌面 UI；依赖错误可辨识；关闭 UI 不遗留组件 |
| A02 | 加密测试 / 真实只读 | 双方核对完整设备公钥；只读视频显示选定真实屏幕；不能控制输入 |
| A03 | 明确拒绝或取消 | 未批准时不发送真实画面或接收 OS 输入；取消后无残留监听 |
| A04 | 真实控制（主屏） | 在各自明确同意和系统正常权限下，实际鼠标、点击、拖动、滚轮及常用键正常；先同 OS，再跨 OS |
| A05 | DPI/黑边/焦点 | 记录分辨率与缩放；画面与指针位置匹配；黑边/失焦不发送新输入，释放已有输入；不支持组合明确报错 |
| A06 | 正常断开 | 在空白编辑器测试键鼠后，从主控 Esc/断开及被控断开分别结束；查看实际键鼠释放与双方确认状态 |
| A07 | 本机授权撤销/父进程异常 | 在非关键测试桌面进行；使用本机撤销、连接中断等方式验证停止；若未确认释放，明确记录故障，不假设安全 |
| A08 | 会话期限/权限拒绝 | 30秒期限停止；拒绝屏幕录制/辅助功能时不能继续真实控制 |
| A09 | 退出清理 | 关闭应用后确认本次会话的媒体子进程及监听资源退出；不得终止无关进程 |
| A10 | 性能基线 | 记录实际画面、帧率与操作响应；现有960×540/10fps 为研发配置，不宣称1080p60或4K能力 |

## 记录
每项填写 PASS / FAIL / BLOCKED、环境、实际观察、相关非敏感日志及问题编号。勿提交屏幕截图、键入内容、设备私钥和真实连接记录。A01–A10 未经授权实机执行不得标记完成。现有仅 CI 环境，本清单所有物理验收结果待填。M1 的退出条件仍是两台真实电脑间可见、明确授权、可停止的远程控制闭环；M2 不以该清单的存在作为已完成 M1 的证据。
