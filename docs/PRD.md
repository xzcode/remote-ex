# 产品需求 PRD v0.1

日期：2026-11-25；状态：M0 原始需求基线；实现及验收进度见 ROADMAP.md，alpha.1 已发布。

## 定位
个人及小团队用于管理已授权电脑的独立远程桌面工具。无强制账号、无商业平台依赖、自建服务。一个安装包同时提供主控/被控能力，按用户设置启用被控功能。

## 用户流程
1. 初次启动显示本机权限状态，按功能申请屏幕录制、辅助功能等权限；拒绝时说明限制。
2. 用户选择仅局域网或自建信令服务器；生成本机设备身份，注册时领取服务端唯一可读 ID；局域网支持手动地址及身份验证，不依赖公网 ID。
3. 主控输入 ID/IP，发起带能力清单的请求；被控明确显示对端、会话权限并接受/拒绝；首次配对校验短认证码。
4. 双方确认身份与权限后建立媒体与控制通道；持续显示会话、远程输入状态、断开按钮。
5. 可切换画质、屏幕、声音；文件与剪贴板为独立权限；断线重连不得扩大授权。
6. 用户主动启用无人值守后，只有已授权设备可访问；可撤销信任并终止活跃会话。

## 范围与优先级
| ID | 功能 | 阶段 | 验收条件 |
|---|---|---|---|
| F01 | 主控/被控统一客户端 | M1 | 两台真实设备互换角色 |
| F02 | 本地许可、显示器采集及预览 | M1 | 权限拒绝时明确报错，不伪造画面 |
| F03 | WebRTC 局域网屏幕及输入 | M1 | 经确认的键鼠操作在远端生效，断开释放按键 |
| F04 | 信令、注册、ID、在线状态 | M2 | 身份注册、重连、离线超时、路由隔离 |

| F06 | 设备地址簿、会话标签、最近连接 | M3 | 本地保存、搜索分组、可清除记录 |

## 首发边界
M1–M2 先验证 Windows 10/11 与 macOS（ScreenCaptureKit 支持的最低版本待定）；Linux 优先 X11，Wayland 依赖桌面 Portal 能力。初期只支持已登录的普通桌面会话；登录前、锁屏、UAC/安全桌面及无显示器主机不得标为已支持。移动端不阻塞桌面 v1。

## 性能目标（非实测）
局域网 1080p30 基线，逐步达到 1080p60；在支持硬件编解码的环境下争取端到端延迟 P95 ≤50ms；带宽初始目标 2–8 Mbps，依内容调整；4K60 为高级能力目标。低带宽预设 480p15、720p30；1080p30/60；可自定义。测量编码、传输、解码、渲染、RTT 与端到端延迟，区分实际值和估算值。

## 非目标
不自研编码算法、不自研加密算法、不自研 NAT 协议，不把远程访问做成隐蔽监控，不强制上传会话内容，不默认捆绑付费/广告服务。
